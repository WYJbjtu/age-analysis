# Candidate official data portals (not yet downloaded/verified in this repository)

- U.S. Census Bureau, state population estimates: https://www.census.gov/data/datasets/time-series/demo/popest/2020s-state-detail.html
- U.S. Census Bureau, 2010–2020 intercensal: https://www.census.gov/data/tables/time-series/demo/popest/intercensal-2010-2020-state-detail.html
- U.S. BEA, GDP by state: https://www.bea.gov/data/gdp/gdp-state
- U.S. BLS, state/local unemployment: https://www.bls.gov/lau/tables.htm
- Statistics Bureau of Japan, Population Estimates: https://www.stat.go.jp/english/data/jinsui/
- Japanese Cabinet Office, prefectural accounts (2022 series): https://www.esri.cao.go.jp/jp/sna/data/data_list/kenmin/files/contents/main_2022.html
- Japan e-Stat: https://www.e-stat.go.jp/en
- UN World Population Prospects: https://population.un.org/wpp/

Each dataset owner must verify exact downloadable table, source release/vintage, license/terms, geographic coverage, and reference period. A landing-page URL is **not** sufficient as a reproducible data citation. Fill your member-owned `sources.csv` with the exact used table.
