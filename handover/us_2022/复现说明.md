# 复现说明

现有报告、主表和图表已可直接使用。复现不是使用交接包的前置条件。

## 分析与制图
在解压后的根目录打开终端，建议使用Python 3.11及以上和独立虚拟环境。

```text
python -m pip install -r requirements-analysis.txt
python scripts/prepare_us.py
```

脚本读取包内raw，写入processed、qa/validation.json及deliverables中的图表与交接CSV。重跑会覆盖这些同名生成文件，请先另存自己的修改。
requirements-analysis.txt记录此次分析环境的版本；不同操作系统的图像和字体渲染可能略有不同。

## 原始数据
包内已包含所有原始数据，正常复现无需运行下载脚本。
scripts/download_sources.py只对缺失文件下载，但BEA在线地址会滚动更新。若原始BEA文件被移除再下载，得到的可能不是此包固定的2026-09-30版本；不要把新文件与本包结果混用。
原始快照完整性用CHECKSUMS.sha256核对，来源及版本见raw/source_manifest.json和deliverables/数据来源.csv。

## 可选重建Word报告
另行安装python-docx，再运行python scripts/build_report.py。
此脚本生成的是A交付时的固定研究叙事，不会自动解释修改后的数据；改变数据、年份或样本后，必须同步检查报告文字、版本说明和所有统计结果。
重建后需要在Word中逐页检查排版；包内现成报告已通过6页视觉检查。

## 文件校验
```text
python scripts/verify_package.py
```
校验无需第三方库。若你已经重跑或修改成果，校验失败可能是预期变更，应保留原交接包作为基准。
