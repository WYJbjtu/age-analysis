# Member 2 — 2011–2022 年产业模块交接

产业表已与 Member 1 人口表、Member 3 劳动与迁移表统一为 **2011–2022 年，共 12 年、98 个地区、1,176 行**：美国 50 州及 DC 每年 51 行，日本每年 47 个都道府县。年份键一致，美国仍为自然年 CY，日本为财政年 FY，不能把两者解释为完全相同的统计期间。

本模块负责 `data/processed/industry.csv` 和 `member2_industry/`。2026-11-09 的授权本地修复已同步共享合并、来源表和展示入口；当前状态见 [修复记录](../docs/remediation/repair_report_zh.md) 与 [展示入口](../poster/README.md)。下方原有日期记录保留为历史验证结果，不代表本轮文件未改动。

## 交付内容

- `../data/processed/industry.csv`：612 行美国 + 564 行日本；包含制造业、服务业占比，以及名义增加值、GDP 和统计期。
- `prepare_industry.py`：从校验码锁定的官方文件直接生成全部 12 年，无需以已有 2022 年数据作为输入。
- `plot_industry.py`：读取完整年度表，计算统计量并输出下列 6 张图，每张均提供 PNG 与 SVG。
- `trend_summary.csv`：两国各 12 年的地区数、制造业及服务业中位数和上下四分位数，共 24 行。
- `summary.json`：保留 2022 年横截面统计摘要，兼容原交接方式。
- `findings.md`：英文发现、趋势数值、图表位置、局限和汇报讲稿。
- `sources.csv` / `source_manifest.json`：原始表、下载链接、版本、下载日期和 SHA-256。
- `validation.json`：完整年度覆盖及日本 564 个地区年度的 GDP、行业加总和税费核算检查。
- `comparability.json`：处理脚本导出的 CY/FY、人口参考日、制造业分子分母和服务业禁用规则；共享合并 CSV 同时保留逐行口径标记。

## 海报与汇报选图

**正文优先只放制造业 12 年趋势主图**：美国地区中位数由 11.17% 降至 9.65%（−1.52 个百分点），日本由 21.32% 升至 25.20%（+3.87 个百分点）。主图同时回答“如何变化”和“地区差异有多大”，为团队后续老龄化关联分析提供产业背景。不要将这一描述性结果写成老龄化的影响。

如版面允许，再用 2022 年制造业分布图展示全部 98 个地区，辅助回答“中位数是否掩盖差异”。其余四张保留为附录或答辩备用，不必全部放进海报。英文讲稿和常见追问见 [findings.md](findings.md)。

国家配色沿用人口模块：美国蓝、日本紫；构成图的颜色则表示行业，读图时保留各自图例。趋势图直接标出国名、起止中位数和变化，`pp` 表示百分点，差值先用未舍入数值计算再显示。两张服务业趋势图使用相同的 50–85% 放大纵轴并在图下注明，仅用于各国内部解读，不用于比较两国服务业水平。

## 复现

先按根目录 README 安装项目已有依赖，在仓库根目录运行：

```bash
python member2_industry/prepare_industry.py --download
python scripts/validate_data.py
python member2_industry/plot_industry.py
PYTHONPATH=src python -m pytest -q tests member2_industry
```

请保留测试命令中的两个目录。项目默认测试入口仅发现 `tests/`，不会自动执行 Member 2 的模块测试；当前远程 CI 检查共享数据契约，本地上述命令同时检查产业处理和绘图逻辑。

`--download` 仅下载缺失文件到被 Git 忽略的 `data/raw/member2/`；已有文件仍检查 SHA-256 和 ZIP 完整性。官方同名文件若已修订，脚本会停止，需核验新旧版本，不能直接替换校验码。此次复用 2026-11-05 保存的三份官方文件，未混用新的历史版本，没有增加或升级依赖。

处理脚本读取 BEA 逐年数值列及日本每年的独立工作表，计算占比，不插值、不沿用 2022 年数值填补历史年。日本 XLSX 的已公布值由 Python 标准库解析。反复运行可重建相同 CSV 与图表；SVG 移除了时间戳并固定对象标识，便于核对。

## 计算和来源核对

| 项目 | 美国 | 日本 |
| --- | --- | --- |
| 官方来源 | BEA SAGDP2，2026-09-30 修订版 | 内阁府 FY2011–FY2022 县民经济核算 |
| 年度 | CY2011–CY2022 | FY2011–FY2022，每年 4 月至次年 3 月 |
| 版本 | NAICS 2017 | 2008SNA，2015 年基准 |
| 金额单位 | 百万美元，现价 | 百万日元，现价 |
| GDP | line 1 | 各年度表 BL 列 |
| 制造业增加值 | line 12 | 各年度表 I 列 |
| 服务业增加值 | line 92：私人服务业 | 各年度表 BO 列：官方第三产业合计 |
| 地区选择 | 地区表中 50 州及 DC | A 列编码 01–47，排除城市和全国合计 |

两个比例均为 `增加值 / 地区名义 GDP × 100`，使用同一地区同一年的分子分母。日本每年 GDP 另与 `soukatu1.xlsx` 的 `実数` 工作表相应年度列逐一核对，列由年度表头识别。

日本第三产业另与 AD、AH、AP、AQ、AR、AU、AV、AY、AZ、BA、BB、BC 共 12 个大类之和核对，避免重复计算子行业。GDP 核对 `BL = BI + BJ - BK`，保留税费调整。允许公布值以百万日元取整带来的微小误差，不做填补。

2022 年金额与原交付完全相同。此次统一从金额计算占比并保留 10 位小数，美国制造业占比相对旧文件最多变化约 0.000000005 个百分点，只涉及原有舍入精度；图中展示的结论不变。

## 服务业范围与年度解释

服务业继续分国展示。美国包含公用事业但不含政府及政府企业；日本第三产业包含公务及公共教育、医疗等。**年份统一不代表服务业定义统一**，不能比较两国服务业中位数差值、做跨国排名或合并服务业回归。

制造业也保留财政年度、行业分类和地区尺度差异的限制。比例以现价金额计算，变化可能涉及相对价格与 GDP 其他组成变化，不等于实际产量增长。日本 `year=2022` 对应 2022-04 至 2023-03；按团队契约与人口、劳动表的 2022 年键连接时，应保留这一时间差说明。
