## 复现

先按根目录 README 安装项目已有依赖，在仓库根目录运行：

```bash
python member2_industry/prepare_industry.py --download
python scripts/validate_data.py
python member2_industry/plot_industry.py
PYTHONPATH=src python -m pytest -q tests member2_industry
```

`--download` 仅下载缺失文件到被 Git 忽略的 `data/raw/member2/`；已有文件仍检查 SHA-256 和 ZIP 完整性。官方同名文件若已修订，脚本会停止，需核验新旧版本，不能直接替换校验码。此次复用 2026-11-05 保存的三份官方文件，未混用新的历史版本，没有增加或升级依赖。

处理脚本读取 BEA 逐年数值列及日本每年的独立工作表，计算占比，不插值、不沿用 2022 年数值填补历史年。日本 XLSX 的已公布值由 Python 标准库解析。反复运行可重建相同 CSV 与图表；SVG 移除了时间戳并固定对象标识，便于核对。

## 计算和来源核对

| 项目 | 美国 | 日本 |
| --- | --- | --- |
| 官方来源 | BEA SAGDP2，2026-09-30 修订版 | 内阁府 FY2011–FY2022 县民经济核算 |
| 年度 | CY2011–CY2022 | FY2011–FY2022，每年 4 月至次年 3 月 |
| 版本 | NAICS 2017 | 2008SNA，2015 年基准 |
| 金额单位 | 百万美元，现价 | 百万日元，现价 |
| GDP | line 1 | 各年度表 BL 列 |
| 制造业增加值 | line 12 | 各年度表 I 列 |
| 服务业增加值 | line 92：私人服务业 | 各年度表 BO 列：官方第三产业合计 |
| 地区选择 | 地区表中 50 州及 DC | A 列编码 01–47，排除城市和全国合计 |

两个比例均为 `增加值 / 地区名义 GDP × 100`，使用同一地区同一年的分子分母。日本每年 GDP 另与 `soukatu1.xlsx` 的 `実数` 工作表相应年度列逐一核对，列由年度表头识别。

日本第三产业另与 AD、AH、AP、AQ、AR、AU、AV、AY、AZ、BA、BB、BC 共 12 个大类之和核对，避免重复计算子行业。GDP 核对 `BL = BI + BJ - BK`，保留税费调整。允许公布值以百万日元取整带来的微小误差，不做填补。

2022 年金额与原交付完全相同。此次统一从金额计算占比并保留 10 位小数，美国制造业占比相对旧文件最多变化约 0.000000005 个百分点，只涉及原有舍入精度；图中展示的结论不变。

## 服务业范围与年度解释

服务业继续分国展示。美国包含公用事业但不含政府及政府企业；日本第三产业包含公务及公共教育、医疗等。**年份统一不代表服务业定义统一**，不能比较两国服务业中位数差值、做跨国排名或合并服务业回归。

制造业也保留财政年度、行业分类和地区尺度差异的限制。比例以现价金额计算，变化可能涉及相对价格与 GDP 其他组成变化，不等于实际产量增长。日本 `year=2022` 对应 2022-04 至 2023-03；按团队契约与人口、劳动表的 2022 年键连接时，应保留这一时间差说明。
